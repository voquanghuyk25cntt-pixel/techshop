TechShop - Live Demo

This branch (gh-pages) is prepared as a static demo ready to be served by GitHub Pages.

Live URL (expected): https://voquanghuyk25cntt-pixel.github.io/techshop/

Notes:
- The original PHP source has been moved into `php-source/` in this branch for convenience.
- Firebase integration is available in the auth pages but requires you to paste your Firebase config (window.FIREBASE_CONFIG) into the pages or create a firebase-config.js to enable sign-in and order persistence.
- For the full PHP site, copy `php-source/` into XAMPP's htdocs or deploy to a PHP-capable hosting provider.
